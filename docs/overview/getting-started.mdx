The recommended way to get started is to connect your coding agent — Claude Code, OpenAI Codex, GitHub Copilot, or Cursor — to the Tracecat MCP server.
This works with Tracecat Cloud or your own self-hosted instance.

## Connect MCP

Connecting your agent to Tracecat Cloud automatically creates an account for you.
You can also sign up manually via [https://platform.tracecat.com](https://platform.tracecat.com).

## Self-host

Choose a deployment method:

- [Docker Compose](/self-hosting/docker-compose): Run every service on a single host. This is the fastest way to self-host.
- [AWS ECS Fargate](/self-hosting/aws-fargate): Deploy to your own AWS account with Terraform.
- [Kubernetes](/self-hosting/kubernetes): Install the Helm chart on EKS, GKE, or any conformant cluster.
- [Air-gapped deployment](/self-hosting/air-gapped): Run on Kubernetes with no runtime internet access.

See [Architecture](/self-hosting/architecture) for how the services fit together.

### Docker Compose quickstart

Follow the full [Docker Compose guide](/self-hosting/docker-compose) or run the commands below.

```bash
# Setup environment variables and secrets
curl -o env.sh https://raw.githubusercontent.com/TracecatHQ/tracecat/1.1.0/env.sh
curl -o .env.example https://raw.githubusercontent.com/TracecatHQ/tracecat/1.1.0/.env.example
chmod +x env.sh && ./env.sh

# Download Caddyfile
curl -o Caddyfile https://raw.githubusercontent.com/TracecatHQ/tracecat/1.1.0/Caddyfile

# Download Docker Compose file
curl -o docker-compose.yml https://raw.githubusercontent.com/TracecatHQ/tracecat/1.1.0/docker-compose.yml

# Start Tracecat
docker compose up -d
```
