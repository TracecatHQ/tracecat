## `core.ssh.execute_command`

Execute a command over SSH and return stdout, stderr, and exit status.

### Secrets

Required secrets:

- `ssh`: required values `PRIVATE_KEY`.

SSH username.

</ParamField>

<ParamField path="allowed_exit_codes" type="array[integer] | null">

Exit statuses treated as success when raise_on_error is enabled. Defaults to [0].

Default: `null`.

<ParamField path="error_patterns" type="array[string] | null">

Literal, case-sensitive substrings that mark the command as failed when found in stdout or stderr. Only checked when raise_on_error is enabled. Not regular expressions. Up to 20 items of at most 256 characters.

Default: `null`.
