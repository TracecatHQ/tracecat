Agent presets save a model, instructions, tools, skills, and MCP integrations under a slug.
Open `Agents` from the workspace navigation to create one, then run it from a workflow with `ai.preset_agent`.

![Agents page](/img/agents/agents-list.png)

## Configure a preset

Click `Create new`, name the preset, and write instructions in the editor.
Use the `Tools` tab to select the model, allowed Tracecat actions, and MCP integrations, and the `Skills` tab to attach published [skills](/agents/skills).

![Agent preset tools](/img/agents/agent-preset-tools.png)

## Where tools come from

Three sources on the preset side make up what the agent can call, and each suits a
different job.

The preset's own registry actions, chosen in the `Tools` tab, belong to that one agent.
This is the usual home for actions only this agent needs.

MCP integrations attached to the preset, also in the `Tools` tab, bring a connector's
tools straight to the agent. An MCP integration does not need to go through a skill to
reach a preset.

Tools in a skill's [`metadata.tools`](/agents/skills#declare-tools-in-frontmatter)
frontmatter travel with the skill's instructions, so a group of tools that several agents
reuse stays in one place. A skill can declare registry actions and MCP references alike,
and attaching the skill brings the instructions and the tools together.

An agent's effective tool set is the union of the three, which is also what it has in
chat. A `namespaces` restriction on the preset filters the registry actions in that set;
MCP tools are not filtered by it.

A workflow can add a fourth source for one run. The `actions` argument on the
`ai.preset_agent` action replaces the preset's registry actions for that run instead of
adding to them, so registry actions a skill contributed are dropped for the run; MCP
tools, whether attached to the preset or declared by a skill, stay attached, and an empty
list changes nothing. Use it when you want to run a preset with a different tool set in a
single workflow, for example in a test or an eval.

Leave `output_type` unset unless you specifically need structured output for a downstream step.

## Availability

Open source includes presets, [skills](/agents/skills), [secrets and variables](/agents/secrets-variables) in preset instructions, and the MCP catalog connectors.

<Badge icon="lock" color="blue" size="lg" shape="pill">Enterprise Edition</Badge>

Enterprise adds:

- Agent folders and tags to organize the `Agents` page.
- `tool_approvals` and the agent inbox to review tool calls before they run.
- `@` agent mentions in [workspace chat](/agents/workspace-chat#mention-an-agent) and [case comments](/automations/cases/agent-mentions).
