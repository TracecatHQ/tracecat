## Choose which agent answers

In your Tracecat workspace, open `Agents` and select the `#` (Channels) view. Change `Default agent` to switch who answers new direct messages and new threads in channels without a route. To give one channel its own agent, add a route.

1. Under `Channels`, select `Pick a channel` and search for the Slack channel. If it isn't listed, copy its channel ID from the channel details in Slack and paste it into the picker or the `Channel ID` field.
2. Choose the agent for that channel and click `Add`.
3. In the Slack channel, run `/invite @Tracecat`. Start a new thread by mentioning the app.

![Connected Slack workspace showing the default agent and per-channel routing controls](/img/agents/slack-channel-routing.png)

Change the agent on a channel's row to reroute new threads immediately. Remove the row to use the default again. Existing threads keep the agent they started with.

## Manage the connection

Use `Pause` to stop replies temporarily and `Resume` to start them again. If the card shows `Needs reconnect`, click `Reconnect` and approve the app in Slack.

One Slack workspace can connect to one Tracecat workspace through the platform app. To move it, have the admin of the connected Tracecat workspace select `Disconnect` before installing from the new workspace.

## Connect a Slack app

To give one agent its own Slack app, open the saved preset from `Agents`, select its `Channels` tab, and click `Connect` on the `Custom Slack app` card.

Each custom app counts separately toward Slack's installation limit. The shared Tracecat app uses one installation across all its channel routes. See [Slack's app installation limit](https://slack.com/help/articles/115002422943-Usage-limits-for-free-workspaces).

1. Choose a bot name and click `Create in Slack`. Create the app in your Slack workspace with the prefilled manifest. If you already created an unused app for this preset, apply the manifest under `Create the app by hand instead` to that app and select `I already have the app`.
2. In Slack, open `Basic Information → App Credentials`. Enter the `Client ID`, `Client secret`, and `Signing secret` in Tracecat. For Socket Mode, generate an app-level token with `connections:write` and paste its access and refresh tokens when prompted.
3. Click `Connect to Slack` and approve the installation. Invite the bot to a channel with `/invite` and its own name, then mention it there.

![Custom Slack app dialog showing the credentials for a single preset and the Connect to Slack button](/img/agents/slack-custom-app.png)

For a walkthrough of the Slack side of manual setup, see [Slack's guide to creating an app from a manifest](https://docs.slack.dev/app-manifests/configuring-apps-with-app-manifests/).

### Earlier setup flow

If your dialog offers `Create app` and `Existing App`, choose the option that matches your app.

- For a new app, choose `Create app`. Copy the manifest into Slack and install the app, then select `Next` in Tracecat.
- For an existing app dedicated to this preset, select `Existing App`. Add the dialog's OAuth redirect URL under `OAuth & Permissions`. Use its endpoint URL for both event subscriptions and interactivity, and subscribe to `app_mention`.

Enter the credentials in Tracecat and click `Connect to Slack`. If you later use `Rotate endpoint`, update both request URLs in Slack.

## Approve tool calls in Slack

When a preset requires approval for a tool, the agent posts the tool name and arguments in the Slack thread. Choose `Approve` or `Deny` on each pending call. The agent continues after every call in the batch has a decision. To edit arguments before approving, open the run in the [agent inbox](/agents/human-in-the-loop#review-tool-calls-in-the-inbox).
