Your organization needs the Agent Channels preview entitlement (`agent_channels_preview`) to [install the shared Slack app](/agents/ai-slackbot) or use the new custom app setup.

## Choose which agent answers

In `Agents → # (Channels)`, the `Default agent` answers DMs and channels without a route. Add a route for any channel that needs a different agent.

1. Select `Pick a channel`. Search by name or paste the channel ID from Slack.
2. Choose the agent and click `Add`. In Slack, run `/invite @Tracecat` in that channel.

![Default agent and channel routes](/img/agents/slack-channel-routing.png)

Change the agent on a row to reroute new threads. Remove the row to use the default. Existing threads keep their agent.

<Accordion title="Pause, reconnect, or move the app">
  Use `Pause` and `Resume` to stop and restart replies. If you see `Needs reconnect`, click `Reconnect` and approve the app in Slack.

  Each Slack workspace connects to one Tracecat workspace. To move it, ask the current workspace admin to `Disconnect` it first.
</Accordion>

## Connect a Slack app

Each custom app has its own bot name and icon and counts toward [Slack's installation limit](https://slack.com/help/articles/115002422943-Usage-limits-for-free-workspaces).

1. Open the preset's `Channels` tab. Under `Custom Slack app`, click `Connect`.
2. Choose a bot name, click `Create in Slack`, and create the app.
3. From Slack's `Basic Information → App Credentials`, copy the client ID, client secret, and signing secret into Tracecat. Enter any Socket Mode tokens the form requests.
4. Click `Connect to Slack` and approve. Invite the bot by name with `/invite`.

<Accordion title="Custom app credentials and manifest">
  ![Custom Slack app credential fields](/img/agents/slack-custom-app.png)

  For Socket Mode, generate an app-level token with `connections:write` and enter its access and refresh tokens.

  To use an unused app dedicated to this preset, copy the manifest under `Create the app by hand instead`, apply it in Slack, and select `I already have the app` in Tracecat. See [Slack's manifest guide](https://docs.slack.dev/app-manifests/configuring-apps-with-app-manifests/).
</Accordion>

<Accordion title="Earlier setup flow" id="earlier-setup-flow">
  Organizations with `agent_channels` alone see `Create app` and `Existing App`.

  - Choose `Create app` to copy the manifest into Slack. Install the app, then click `Next` in Tracecat.
  - Choose `Existing App` for an app dedicated to this preset. Add the OAuth redirect URL under `OAuth & Permissions`. Use the endpoint URL for events and interactivity, and subscribe to `app_mention`.

  Enter the credentials and click `Connect to Slack`. If you rotate the endpoint later, update both request URLs in Slack.
</Accordion>

## Approve tool calls in Slack

Choose `Approve` or `Deny` for each pending tool call in the thread. To edit arguments before approving, open the run in the [agent inbox](/agents/human-in-the-loop#review-tool-calls-in-the-inbox).
