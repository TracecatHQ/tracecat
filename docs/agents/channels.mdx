Your organization needs the Agent Channels preview entitlement (`agent_channels_preview`) to [add Tracecat to Slack](/agents/ai-slackbot) or connect a custom Slack app.

## Capabilities

- Direct messages: the agent answers every message.
- Channels: the agent answers messages that mention it, in channels you invited it to.
- Threads: each thread is one agent session, so the agent remembers earlier turns in that thread.
- Channel routing: each channel can have its own agent. The default agent answers direct messages and channels without a route.
- Tool approvals: approve or deny a tool call from the thread. The card then shows who decided.

## Choose which agent answers

In `Agents → # (Channels)`, the `Default agent` answers direct messages and channels without a route. Add a route for any channel that needs a different agent.

1. Select `Pick a channel`. Search by name or paste the channel ID from Slack.
2. Choose the agent and click `Add`. In Slack, run `/invite @Tracecat` in that channel.

![Default agent and channel routes](/img/agents/slack-channel-routing.png)

Change the agent on a row to reroute new threads. Remove the row to use the default. Existing threads keep their agent.

<Accordion title="Pause, reconnect, or move the app">
  Select `More actions → Pause` to stop replies and `More actions → Resume` to restart them. If you see `Needs reconnect` or `Update needed`, click `Reconnect` and approve the app in Slack.

  To connect the Slack workspace to a different Tracecat workspace, first select `More actions → Disconnect` in the current one.
</Accordion>

## Connect a Slack app

Each custom app has its own bot name and icon and counts toward [Slack's installation limit](https://slack.com/help/articles/115002422943-Usage-limits-for-free-workspaces).

1. Open the preset's `Channels` tab. Under `Custom Slack app`, click `Connect`.
2. Choose a bot name, click `Create in Slack`, and create the app.
3. From Slack's `Basic Information → App Credentials`, copy the client ID, client secret, and signing secret into Tracecat.
4. Click `Connect to Slack` and approve. Invite the bot by name with `/invite`.

<Accordion title="Socket Mode tokens and manual app setup">
  For Socket Mode, generate an app-level token with `connections:write` and enter its access and refresh tokens.

  ![Custom Slack app credential fields](/img/agents/slack-custom-app.png)

  To use an unused app dedicated to this preset, copy the manifest under `Create the app by hand instead`, apply it in Slack, and select `I already have the app` in Tracecat. See [Slack's manifest guide](https://docs.slack.dev/app-manifests/configuring-apps-with-app-manifests/).
</Accordion>

<Accordion title="Earlier setup flow" id="earlier-setup-flow">
  Organizations with `agent_channels` alone see `Create app` and `Existing App`.

  - Choose `Create app` to copy the manifest into Slack. Install the app, then click `Next` in Tracecat.
  - Choose `Existing App` for an app dedicated to this preset. Add the OAuth redirect URL under `OAuth & Permissions`. Use the endpoint URL for events and interactivity, and subscribe to `app_mention`.

  Enter the credentials and click `Connect to Slack`. If you rotate the endpoint later, update both request URLs in Slack.
</Accordion>

## Limitations

- In a channel thread, mention the agent in every message you want it to answer. The agent doesn't receive messages that don't mention it.
- The agent reads message text only, not files or attachments.
- While a tool call awaits approval, the agent doesn't accept new messages in that thread.
- To edit a tool call's arguments before you approve it, use the [agent inbox](/agents/human-in-the-loop#review-tool-calls-in-the-inbox).
- Each Slack workspace connects to one Tracecat workspace through the platform app.
