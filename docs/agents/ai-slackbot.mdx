## Add Tracecat to Slack

Your Tracecat organization needs the Agent Channels preview entitlement (`agent_channels_preview`).
You need a [saved preset](/agents/ai-preset-agent#configure-a-preset), `agent:update` in the workspace, and permission to install Slack apps.

1. Open `Agents` and select the `#` (Channels) view.
2. Choose a `Default agent` and click `Add to Slack`. The default agent answers direct messages, so anyone in your Slack workspace can use its tools.
3. In the same browser, select your Slack workspace and click `Allow`. Back in Tracecat, check that `Tracecat for Slack` shows `Active`.

![Default agent and Add to Slack](/img/agents/slack-add-to-workspace.png)

## Get your first reply

1. Run `/invite @Tracecat` in a channel whose members should have access to the agent's tools and approvals.
2. Send `@Tracecat What can you help me with?` Mention the app in the reply thread to continue.

To use a different agent in that channel, [add a channel route](/agents/channels#choose-which-agent-answers).

<Accordion title="Can't install the app?">
  If the Channels view is missing, ask your administrator to check the preview entitlement and [platform app registration](/manage-platform/slack-app).
  For a bot dedicated to one preset, [connect a custom app](/agents/channels#connect-a-slack-app).

  Free Slack workspaces allow 10 app installations. For workspace restrictions, see [Slack's app limits](https://slack.com/help/articles/115002422943-Usage-limits-for-free-workspaces) and [app approval settings](https://slack.com/help/articles/222386767-Manage-app-approval-for-your-workspace/).
</Accordion>
