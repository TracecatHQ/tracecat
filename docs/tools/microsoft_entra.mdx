- `microsoft_entra_oauth`: OAuth token `MICROSOFT_ENTRA_USER_TOKEN`.
- `microsoft_entra_oauth`: OAuth token `MICROSOFT_ENTRA_SERVICE_TOKEN`.

### Input fields

<ParamField path="updates" type="object" required>

User properties to update as defined in the Microsoft Graph user resource.

</ParamField>

<ParamField path="user_id" type="string" required>

The unique identifier of the user to update.

</ParamField>

<ParamField path="api_version" type="string">

Microsoft Graph API version.

Default: `"v1.0"`.

</ParamField>

<ParamField path="base_url" type="string | null">

Microsoft Graph host, without the API version. If omitted, uses the workspace variable `microsoft_entra.base_url`, then https://graph.microsoft.com. National clouds: https://graph.microsoft.us (US Government L4) and https://dod-graph.microsoft.us (US Government L5 DOD).

Default: `null`.

</ParamField>
