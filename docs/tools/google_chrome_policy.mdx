## Batch inherit org unit policies

Action ID: `tools.google_chrome_policy.batch_inherit_org_unit_policies`

Modify multiple policy values that are applied to a specific org unit so that they now inherit the value from a parent (if applicable). All targets must have the same target format. Use it to undo `batch_modify_org_unit_policies` or `block_extension` on a child org unit.

Reference: [https://developers.google.com/chrome/policy/reference/rest/v1/customers.policies.orgunits/batchInherit](https://developers.google.com/chrome/policy/reference/rest/v1/customers.policies.orgunits/batchInherit)

### Secrets

Optional secrets:

- `google_admin_oauth`: OAuth token `GOOGLE_ADMIN_USER_TOKEN`.
- `google_admin_oauth`: OAuth token `GOOGLE_ADMIN_SERVICE_TOKEN`.
- `google_api`: required values `GOOGLE_API_CREDENTIALS`; optional values `GOOGLE_API_SUBJECT`.

### Input fields

<ParamField path="requests" type="array[object]" required>

List of policies that have to inherit their values. Each request has `policyTargetKey` (`targetResource` and `additionalTargetKeys`, such as `&#123;"app_id": "chrome:&lt;extension_id>"&#125;`) and `policySchema`, the fully qualified name of the policy schema that is being inherited. All requests in the list must follow these restrictions: all schemas in the list must have the same root namespace; all `policyTargetKey.targetResource` values must point to an org unit resource (`orgunits/&#123;orgunit_id&#125;`); all `policyTargetKey` values must have the same key names in the `additionalTargetKeys`; and no two requests can reference the same `policySchema` + `policyTargetKey` pair.

</ParamField>

<ParamField path="customer" type="string">

ID of the Google Workspace account or literal "my_customer" for the customer associated to the request.

Default: `"my_customer"`.

</ParamField>

## Block extension

Action ID: `tools.google_chrome_policy.block_extension`

Block a Chrome extension for an org unit by setting the `chrome.users.apps.InstallType` policy to `BLOCKED`. Blocking removes the extension from managed browsers and profiles in the org unit and stops users from installing it. Undo it with `batch_inherit_org_unit_policies` on a child org unit.

Reference: [https://developers.google.com/chrome/policy/reference/rest/v1/customers.policies.orgunits/batchModify](https://developers.google.com/chrome/policy/reference/rest/v1/customers.policies.orgunits/batchModify)

- `google_api`: required values `GOOGLE_API_CREDENTIALS`; optional values `GOOGLE_API_SUBJECT`.
