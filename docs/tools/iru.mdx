Reference: [https://api-docs.iru.com/#b70f2ddc-cc1b-4b4f-8eec-e481d8a17927](https://api-docs.iru.com/#b70f2ddc-cc1b-4b4f-8eec-e481d8a17927)

### Secrets

Required secrets:

- `iru`: required values `IRU_API_TOKEN`.

### Input fields

<ParamField path="device_id" type="string" required>

Device UUID.

</ParamField>

<ParamField path="asset_tag" type="string | null">

Asset tag to set on the device.

Default: `null`.

</ParamField>

<ParamField path="base_url" type="string | null">

Iru (Kandji) API base URL (e.g. https://acme.api.kandji.io).

Default: `null`.

</ParamField>

<ParamField path="blueprint_id" type="string | null">

Blueprint UUID to assign to the device.

Default: `null`.

</ParamField>

<ParamField path="tags" type="array[string] | null">

Tag UUIDs to assign to the device.

Default: `null`.

</ParamField>

<ParamField path="user" type="string | null">

User UUID to assign to the device.

Default: `null`.

</ParamField>
