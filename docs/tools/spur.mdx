## Lookup API token status

Action ID: `tools.spur.lookup_api_token_status`

## Lookup IP address

Action ID: `tools.spur.lookup_ip`

Retrieve the Spur IP Context Object for an IPv4 or IPv6 address, or the context for a past date when `dt` is set. Calls GET /v2/context/&#123;ip&#125; directly.

Reference: [https://docs.spur.us/context-api/endpoints#lookup-an-ip-address](https://docs.spur.us/context-api/endpoints#lookup-an-ip-address)

### Secrets

Required secrets:

- `spur`: required values `SPUR_TOKEN`.

### Input fields

<ParamField path="ip" type="string" required>

Public IPv4 or IPv6 address to look up.

</ParamField>

<ParamField path="base_url" type="string | null">

Spur API base URL.

Default: `null`.

</ParamField>

<ParamField path="dt" type="string | null">

A datetime in the format YYYYmmdd. Only valid for tokens with the Context API Historical Query permission (Pro plans and above); other tokens get a 401.

Default: `null`.

</ParamField>

<ParamField path="mmgeo" type="integer | null">

A boolean value, that when set to 1, will return MaxMind's GeoLite2 geolocation data instead of Spur's geolocation data in the location object.

Default: `null`.

</ParamField>
