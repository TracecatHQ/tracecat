## Get page content

Action ID: `tools.browserless.get_content`

Render a URL in a managed Chrome browser and return its HTML.

Reference: [https://docs.browserless.io/rest-apis/content](https://docs.browserless.io/rest-apis/content)

### Secrets

Required secrets:

- `browserless`: required values `BROWSERLESS_TOKEN`.

### Input fields

<ParamField path="url" type="string" required>

The URL to navigate to. Must be an http or https URL that resolves to a publicly routable address.

</ParamField>

<ParamField path="base_url" type="string | null">

Default: `null`.

</ParamField>

<ParamField path="best_attempt" type="boolean | null">

Continue and return whatever rendered so far when a `waitFor` or navigation step times out.

Default: `null`.

</ParamField>

<ParamField path="goto_options" type="object | null">

</ParamField>

<ParamField path="timeout" type="number">

Timeout in seconds for the Browserless request.

Default: `30.0`.

</ParamField>

<ParamField path="wait_for_selector" type="object | null">
